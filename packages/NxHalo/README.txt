NxHalo Build14 (v0.1.1-build14)

Experimental native Halo: Combat Evolved campaign port for the original Nintendo Switch. Requires your own supported original Xbox Halo game data; no ROM, maps, executable, shader data or keys are supplied.

INSTALL: This package places Halo_CE_Runtime.nsp in /switch/install/. Install it through DBI, then launch Halo CE from HOME. This package does not launch directly from hbmenu or install a HOME title automatically.

DATA: On a computer, get the offline NxHalo setup app from the linked GitHub release. Select your complete Xbox game image/folder and SD root. It prepares /switch/halo/maps/, including shaders.bin. Users moving from private builds must import shaders once; existing public Build13 data can be retained.

Build14 keeps the vehicle/camera corrections and adds RAM transient checkpoints. Battle/shader stutter and visual/audio issues remain; full campaign is under testing and multiplayer is unsupported. Back up saves before updates. Full guide and source/component notices are on GitHub.
